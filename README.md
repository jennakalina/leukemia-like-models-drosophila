# leukemia-like-models-drosophila
Code used in the bioinformatics analysis for "A comparative single-cell transcriptomic analysis of Drosophila Leukemia-like blood models" (Tattikota et al.)

## Directories

**scripts** contains all scripts used for bioinformatics analysis.

**data** contains supplementary files with the markers for the Cho et al. (2020) and Fu et al. (2020) papers that
was used to compare the PM4 cluster to defined clusters in literature.
